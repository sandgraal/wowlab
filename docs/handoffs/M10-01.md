# M10-01 — handoff

Facts for the implementer. Written 2026-09-20 with the Lab track docs.

## Expected wiring

Root `pyproject.toml`:

```toml
[project]
dependencies = ["bronze-api", "wowlab-core"]

[tool.uv.workspace]
members = ["api", "lab/core"]

[tool.uv.sources]
bronze-api = { workspace = true }
wowlab-core = { workspace = true }

[tool.ruff.lint.isort]
known-first-party = ["bronze_api", "wowlab_core"]

[tool.mypy]
files = ["api/src", "lab/core/src"]

[tool.pytest.ini_options]
testpaths = ["api/tests", "lab/core/tests", "tests"]
```

`lab/core/pyproject.toml`: name `wowlab-core`, `requires-python = ">=3.12"`,
hatchling, `packages = ["src/wowlab_core"]`,
`[project.scripts] wowlab = "wowlab_core.cli:app"`. Runtime dependencies for
this ticket: `typer` and `pydantic` only; later tickets add `httpx`,
`platformdirs`, `psutil` when they first need them.

`Makefile`:

```make
test-parser:
	$(UV) run --frozen pytest -m parser api/tests/parser lab/core/tests/parser
```

`lab/core/tests/parser/` needs an `__init__.py`-free layout that does not
collide with `api/tests/parser` module names under rootdir-relative imports;
if pytest reports a duplicate module basename, use distinct file names
(`test_lab_*.py`) rather than changing the import mode repository-wide.

Regenerate `uv.lock` with `uv lock`; never hand-edit it.

## CI

- `.github/workflows/ci.yml`: the existing `API lint, typecheck, tests` and
  `Parser fixtures and determinism` jobs pick the Lab up through the root
  config; do not rename them (the branch ruleset requires them by name).
- New job `lab (windows)`: `windows-latest`, pinned action SHAs like the
  other jobs, `permissions: contents: read`, `uv sync --frozen`,
  `uv run --frozen pytest -q lab/core/tests`. Not added to the ruleset.
  Skip cleanly on doc-only PRs using the existing `changes` job output.
- The doc-only filter treats `lab/**` as code already (it only excludes
  `docs/**/*.md` and the root markdown files).
