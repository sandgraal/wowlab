# M13-05 — owner runbook: the schema-3 capture (about 15 minutes in game)

The schema-3 addon code merged (#176). What is left needs you at the game: one
login on one character, a small action-bar setup, a logout, and one capture
command. The optional M11-29 barber-shop check can ride along in the same
session (section 3).

Nothing here is committed by you. You run the commands and tell the next
session "capture done", with the tool's summary lines and the notes asked for
below. An agent commits the fixtures, and reviewers check them before anything
is public. The full list of what the capture settles is in
`lab/addon/README.md`, "M13-05 [verify] checklist". If this file and the
README disagree, the README wins.

Each command is meant to be pasted from your wowlab folder. Your install is
`~/Games/World of Warcraft`.

## 1. Get ready (client closed)

```bash
git switch main && git pull && make setup
```

Check the install plan. It should name only paths under
`Interface/AddOns/WowLab/` and an `## Interface:` line that matches your game:

```bash
uv run wowlab addon install lab --root "$HOME/Games/World of Warcraft" --dry-run
```

Install it. It asks before writing, and `wowlab undo` reverses it:

```bash
uv run wowlab addon install lab --root "$HOME/Games/World of Warcraft"
```

## 2. In game, on one character

1. **Log in out of combat.** Don't be in a vehicle or skyriding, because both
   swap the main bar. Wait for the chat line "WowLab: recording in 15 s" to
   pass. If you never see it, type `/wowlab`; it answers with two lines
   starting `WowLab:`. If nothing answers, stop and report it.
2. **Put these on an action bar:**
   - one spell;
   - one item;
   - a macro whose first line is `#showtooltip <a spell you know>`;
   - a plain macro with no `#showtooltip`, for example `/say hi`.
3. **Open the key bindings panel once.** Note whether "Character Specific Key
   Bindings" is ticked. If the client lets you drag a spell straight onto a
   key there, do it once. If you use an action-bar addon, bind one of its
   buttons to a key too.
4. **Open the spellbook.** Note whether it has a "show all ranks" toggle, and
   whether ranks show as text such as "Rank 3". If there is a toggle, note
   whether it is on or off when you log out, because the file reflects that
   state. If you can see a spell you
   haven't learned yet, note its name. That note stays private; you tell the
   next session only whether one was there.
5. **Doing M11-29 as well?** Do section 3 now, before you log out.
6. **Log out cleanly**, then exit the client. The file is only complete after
   logout.

If the client crashes at login: at character select, untick **WowLab**, and
report the `Error:` line plus the topmost `Interface/AddOns/WowLab/...` file and
line from the crash report. Never paste the whole report anywhere: it holds
your character name, GUID, BattleTag and guild roster.

## 3. Optional: the M11-29 barber-shop check (costs gold, permanent)

Do this only if you want to close M11-29 in the same session. Use the same
character, before the logout in step 2.6.

- Note the position of the current swatch and of the one you pick, counting
  from 1, left to right and then top to bottom. For example: "hair colour: 7th,
  then 3rd".
- Sit once, change **one colour only** (not the body type), and click Accept
  once. Note whether the shop closed by itself. Check that the new colour shows.
- Don't cancel, and don't sit down again: a second sit spoils the counts.
- If the barber shop does not open at all, log out, capture anyway and report
  it. Don't redo it.
- No `/reload` between the visit and the logout, and don't log that character
  in again before the capture.

The full version is `docs/handoffs/M11-29.md`.

## 4. Capture (client closed)

The tool copies files out of the install and replaces every name it finds with
a pseudonym. It never writes to the install. It also copies `macros-cache.txt`
and `bindings-cache.wtf`, and it does not rewrite macro names or bodies. Read
every line it marks `look`, and read `macros-cache.txt` in full: a macro that
names a player stays as it is. Only the files the next session picks are
committed, and reviewers check them, but name nothing in a macro you would not
publish. With no `--character` it takes the
character you played last, so you don't type any names.

```bash
git switch -c m13/05-schema3-capture origin/main
```

Dry run first. Read what it plans to copy:

```bash
uv run python scripts/lab_capture.py --root "$HOME/Games/World of Warcraft" --out lab/core/tests/fixtures/incoming/m13-05 --flavor _classic_beta_ --kind _classic_beta_=forever --sv WowLab.lua --own-guid "$(cat ~/.config/wowlab/own-guid)" --dry-run
```

Then the real run, which is the same command without `--dry-run`:

```bash
uv run python scripts/lab_capture.py --root "$HOME/Games/World of Warcraft" --out lab/core/tests/fixtures/incoming/m13-05 --flavor _classic_beta_ --kind _classic_beta_=forever --sv WowLab.lua --own-guid "$(cat ~/.config/wowlab/own-guid)"
```

- If the dry run names a flavor folder other than `_classic_beta_`, use that
  name instead in both commands. The folder name changes at launch.
- If a run says `REFUSED`, don't edit anything. Paste the refusal; it never
  prints a name.

Stop there and do not commit. Tell the next session "M13-05 capture done"
(and "M11-29 done" if you did section 3). Include the tool's summary lines and
these notes:
- whether "Character Specific Key Bindings" was ticked;
- whether the spellbook has a "show all ranks" toggle;
- whether ranks show as text;
- whether you saw a spell you haven't learned yet;
- for the barber shop: the swatch positions, whether the shop closed by itself,
  and whether the colour changed.

## Optional extras for a later session

## What the next session does with it

An agent commits the scrubbed files with provenance rows. It reads the capture
against the README's M13-05 checklist (and the M11-29 table, if you did
section 3), records what it settled in a dated `docs/LAB_FORMATS.md`
amendment, and closes M13-05. That unblocks M13-06 (`wowlab macros check`),
which ships in v0.1 if it lands in time.
