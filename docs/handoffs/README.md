# Handoffs

Notes addressed to the agent that will pick up a specific ticket, written by
whoever learned something the backlog does not say (a reviewer, the
conductor, the owner). Name the file after the ticket: `M1-02.md`. Keep it
to facts: what was tried, what was found, which decision was made and why.
Agents read `docs/handoffs/<ticket>.md` in their setup step if it exists.
