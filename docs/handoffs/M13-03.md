## Install as a stranger would

folders all pointed into a throwaway folder, `/tmp/wowlab-rc1-test`, so nothing
came from the repository, the owner's uv cache or the owner's home folder.

```
HOME=/tmp/wowlab-rc1-test UV_CACHE_DIR=/tmp/wowlab-rc1-test/cache UV_TOOL_DIR=/tmp/wowlab-rc1-test/tools UV_TOOL_BIN_DIR=/tmp/wowlab-rc1-test/bin uv tool install --python 3.12 https://github.com/sandgraal/wowlab/releases/download/v0.1.0rc1/wowlab_core-0.1.0rc1-py3-none-any.whl

Result: 21 packages were resolved and installed (`wowlab-core==0.1.0rc1` from the
release URL), along with one executable, `wowlab`.

```

printed the full first-run trust statement. That is the M13-04 text, which says
that with `--offline` no request is sent. It then printed these, and nothing
was changed:
- "no install found at the default locations", with instructions for `--root` and `WOWLAB_WOW_ROOT`, as expected in a throwaway home;
- a snapshot store under the throwaway home, not yet created, with 0 snapshots and none damaged;
- "this run changed nothing in your install, so there is nothing to undo".

The stranger was approximated by a throwaway home folder, not a separate macOS
user account.
