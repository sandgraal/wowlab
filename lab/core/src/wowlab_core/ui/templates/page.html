wowlab

What every file in your game folder is, who writes it, and whether wowlab may change it. The explorer only reads, and nothing on this page changes your game files; the Commands tab can save to wowlab's own data (snapshots, profiles, saved looks).

    Paths in the install that no file-map row describes, grouped under the row of the folder they are in and ranked by how many files they hold, then paths only a catch-all row describes, folders labelled whole and not looked inside, and links, which are never followed. Read only.

    Runs the commands of the wowlab you started, on this machine only. Commands that save only to wowlab's own data (snapshots, profiles, saved looks, the db2 cache, pages) are offered, and none of them touches the game folder. A command that asks before changing anything (--yes) runs first as a plan, which changes nothing, and runs for real only when you press Confirm under that plan; in this version that is snap gc and doctor, which change only wowlab's own store. Commands that change your game files are not offered in this version.
