    Runs the commands of the wowlab you started, on this machine only. Reading never changes anything. Six commands can change game files; each shows a plan and runs only when you confirm, after a snapshot. They are snap restore, undo, profile apply, sv merge, addon install and addon remove, and wowlab undo reverses them. A command that asks before changing anything (--yes) runs first as a plan, which changes nothing, and runs for real only when you press Confirm under that plan. snap gc and doctor change only wowlab's own store, and the other commands save only to wowlab's own data (snapshots, profiles, saved looks, the db2 cache, pages). Two of them refuse to run when something changed after the plan: undo, when a newer change has been journaled, and sv merge, when its target file changed. The others apply what is there when you confirm, after the snapshot that wowlab undo restores from.
