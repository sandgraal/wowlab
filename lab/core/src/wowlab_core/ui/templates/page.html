        About this data

        Runs the commands of the wowlab you started, on this machine only. Reading never changes anything. Six commands can change game files; each shows a plan and runs only when you confirm, after a snapshot. They are snap restore, undo, profile apply, sv merge, addon install and addon remove, and wowlab undo reverses each of them. Two of them refuse to run when something changed after the plan: undo, when a newer change has been journaled, and sv merge, when its target file changed. The others apply what is there when you confirm, after the snapshot that wowlab undo restores from. The plan changes nothing; press Confirm under it to run the command for real. snap gc and doctor also ask first (--yes) and change only wowlab's own store. The commands that only read, or save only to wowlab's own data (snapshots, profiles, saved looks, the db2 cache, pages), run directly.

        About this data

        The page wowlab looks page writes: the races, body types, classes and customization options of the build's tables, and your saved looks checked against that build. Download tables and write the page runs that command. It downloads the build's public game tables from wago.tools when wowlab does not have them yet, sending your game version, then writes pages/looks.html in wowlab's own data folder, never touching your game folder, and shows that file here. The page itself runs in a closed frame: only its own script, no network requests, and nothing it can reach on this page.
