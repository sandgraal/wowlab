# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work,
and remember that the person on the other side of a review thread may be
new to WoW, new to Python, or both. Harassment, gatekeeping ("git gud"), and
shaming players for their performance are not acceptable here — the product
itself is built on the principle that analysis is diagnostic, never a score
to mock.

Report concerns privately to the repository owner via GitHub. Reports are
handled confidentially.
